# Common Keys — compact Salamander piano

Salamander Grand Piano V3 — Alexander Holm. Retuned mapping: Markus Fiedler. Derived from the user-supplied V3+20161209 44.1 kHz/16-bit distribution.

Source: https://archive.org/details/SalamanderGrandPianoV3

License: CC-BY-3.0 — https://creativecommons.org/licenses/by/3.0/

Changes: Trim leading silence at -55 dB, mono 32 kHz PCM16, short non-looped edits with 40 ms end fade. One shared peak gain per root note or drum sound preserves relative layer and RR dynamics while balancing registers. Curated subsets expand selected layers to cover velocities 1–127; not a complete SFZ emulation.
