地底深处，
有三首歌在发光。

一座集市、一条晶脉、一位守卫。三首原创游戏配乐，每一个音符都写在 JSON 乐谱里，由 Retro Music Toolkit 在本机离线渲染成可无缝循环的音频。

播放时，背景的洞穴会换成那首曲子的地貌，核心随节拍跳动。

三层矿脉，三种写法

同一个工具，三套完全不同的声音：采样管弦、减法合成、NES 四通道。每首都附创作提示词、完整乐谱和渲染报告。

把它们带进你的游戏

三首曲子都可用于个人和商业项目。WAV 首尾相接即可无缝循环；乐谱是普通 JSON，可以改旋律、换音色，再用同一个工具重新渲染。

苔光集市和晶脉潜流用到了署名许可的采样（钢琴 CC BY 3.0、鼓组 CC BY 4.0），发布时请保留每首曲目下方列出的署名。熔芯守卫全部是合成音色，无需署名。 查看完整出处与许可

旋律与编曲均为原创，不使用任何商业游戏的旋律或采样。MP3 用于试听，WAV 用于交付。
