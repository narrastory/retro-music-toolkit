# AI 作曲与修订操作手册

## 从场景到音乐

先写一句用途，例如“玩家在黄昏港口探索，平静但带一点前进感”。确定主音色、速度、主题长度和循环结构。没有特定要求时，先写 16 小节；不要为了复杂而写很多不同材料。

以 4/4 为例可用 A1(4小节) → A2(4小节) → B(4小节) → A回归(4小节)。A2 保留主要节奏，改变句尾；B 改变音区、密度或配器之一；回归让熟悉动机重新出现。energy 只是注释，必须用具体音符和声部安排实现。

## 先写调性与和声，再写旋律

1. 定一个调（`key`）和 4–8 个和弦（`harmony`）。和弦进行决定了旋律可以去哪里。
2. 旋律先落在强拍的和弦音上，弱拍再用经过音、辅助音制造流动。
3. 用 `diagnose` 检查和声冲突；强拍非和弦音若不是有意为之，通常就是写错了。
4. 需要伴随时用 `harmonize` 生成骨架，再手动改写——不要原样交付自动排列。

## 主旋律

1. 用 1–2 小节节奏建立身份，再填入音高。
2. 保留一部分节奏重复，避免每小节换新动机。
3. 检查重拍、长音与当前低音/和声的关系，经过音可以有意产生张力。
4. 句尾留呼吸，让回答声部有位置。
5. 跨小节的延音用 `hold: true`，不要为了长音把 pattern 拉长。
6. 先用单一朴素音色听旋律与低音。去掉鼓后仍应有方向。

## 让 16 小节不腻

| 手法 | 工具 | 注意 |
| --- | --- | --- |
| 保留动机，只换句尾 | `vary --mode ending` | 最安全，适合 A2 |
| 模进（上一句整体上移） | `motif` + `transpose degrees` | 连续模进超过两次会显得机械 |
| 倒影 / 逆行 | `motif` + `invert` / `retrograde` | 结果不一定好听，必须试听 |
| 时值增减 | `motif` + `scaleDuration` | 减值（0.5）常用于推向高潮 |
| 减一个声部 | clip `mute` 或 `lengthBeats` | 比加声部更能制造对比 |
| 换音区重复同一动机 | `motif` + `transpose` ±12 | 8bit 里第二脉冲唱高八度很常见 |

工具可以分析结构，但不会自动理解“这句更有故事感”。不要为优化数字指标牺牲音乐意图。

## 8bit

优先分配两路脉冲、一条三角低音和一条鼓线。此工具的 chip-drums 含合成 kick 和噪声打击，是现代风格近似，不能当作 NES Noise 原生电路模拟。

让第二脉冲在主旋律停顿时回答；不要长期与主旋律同音区密集运动。先调 gate、包络与力度，再考虑更复杂效果。需要回声时思考第二脉冲承担回声与承担和声的取舍；现代 delay 虽然可用，也要标明它是扩展。

避免全程快速琶音、持续高音和长噪声镲。高潮可以来自先前静音的声部回归，不必增加主音量。

## FM

选择一个主角音色，用另一种较软音色支撑。调制指数过大、长音又多时容易疲劳。先降低 brightness，缩短伴奏音长；不要只靠全曲低通补救拥挤。

让低音和底鼓在音长与瞬态上互补。电钢琴适合短和声与回答，铜管更适合少量有方向的旋律句。这里的 FM 为 Tone.FMSynth 两运算器结构，不是 Mega Drive 四运算器完整复现。

## 采样

内置 flute、strings、pluck、bass 是程序生成的教学音色，没有真实管弦录音库的细节。strings 起音较慢，需要更长音；pluck 即使 nominal duration 很长，源声音也会自行衰减。

先保证干声层次，再加少量共享 delay。主旋律与弦乐可以 send，低音与底鼓通常保持较干。三音和弦占三个声部，release 也要计入预算。采样源循环与整首音乐循环是两个不同问题。

## 一次解决一个主要问题

| 听到的症状 | 首选动作 |
| --- | --- |
| 记不住主题 | 保留节奏，减少新材料，重复后变句尾 |
| 主旋律被盖住 | 伴奏让拍、降音区或缩 gate，再调音量 |
| 低音拖沓 | 缩短音长，与鼓错开持续段 |
| 全曲没有发展 | 先抽空一段，再恢复关键声部 |
| 尖锐疲劳 | 降音区、减少高频打击密度，再调 brightness |
| 采样旋律说不清 | 改长音或换快起音 preset |
| 循环每次像重新开始 | 改末句呼吸与和声去向，再检查技术边界 |
| 接缝点击 | 检查尾音、预热和波形变化，不直接长交叉淡化 |

记录版本和一句修改意图。比较相近响度的相同片段。完成标准包括主题身份、层次、段落变化、反复试听耐受和目标场景适配；这些要用真实听觉判断。
