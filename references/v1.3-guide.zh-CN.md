# 1.3：常用音色扩充、力度分层与轮换采样

新增 6 件常用音色，分别放在三个独立许可的轻量包中。原有 11 个程序预设和 4 件 starter 采样乐器保留。

| 包 | ID | 用途 | 采样数 | 许可 |
| --- | --- | --- | --- | --- |
| band | `band-bass` | 普通电贝斯（E1–C4，六个根音），两个代表力度层、两次轮换 | 24 | CC0-1.0 |
| band | `band-bass-short` | 短奏贝斯（E1–C4，六个根音），两次轮换 | 12 | CC0-1.0 |
| band | `band-guitar` | 干净电吉他，两个代表力度层、两次轮换 | 12 | CC0-1.0 |
| band | `band-guitar-short` | 短奏干净电吉他，两次轮换 | 6 | CC0-1.0 |
| piano | `keys-grand` | 四个根音、两个代表力度层的钢琴 | 8 | CC-BY-3.0 |
| drums | `drums-acoustic` | 底鼓、军鼓、闭镲、开镲、通鼓，各两层两轮换 | 20 | CC-BY-4.0 |

新增包共约 5.7 MB / 82 个采样。使用单声道 32 kHz PCM16，截短并淡出；同一根音或鼓件共享增益，以保留力度层与轮换之间的相对变化。这些是不带持续循环点的短采样，不是完整原音源的替代品。

## 选择和导入

在 `scripts/runtime` 中构建后：

```bash
node dist/cli.js instrument-packs --all
node dist/cli.js instrument-packs --pack band
node dist/cli.js import-pack song.json --pack band --instrument band-bass,band-guitar --out with-band.json
node dist/cli.js import-pack with-band.json --pack piano --out with-piano.json
node dist/cli.js instruments --score with-piano.json
```

导入后使用 `patch` 的 `set-track`，或直接修改轨道的 `instrument` 字段。默认不传 `--pack` 仍使用 starter，保持 1.2 的调用兼容。
`--definition` 可指向其他本地集合清单，与 `--pack` 互斥。`instrument-packs --all` 返回所有内置集合；默认命令仍返回 starter，并通过 `availablePacks` 提供其他集合摘要。
素材只会从正式 `instruments/<pack>/samples/` 读取并内嵌到乐谱中，运行、网页上传与可移植导出均不依赖原始 material 目录。

## 音高校验与过期乐器（band 1.1.0 / starter 1.1.0）

band 1.0.0 的贝斯根音整体高标了一个八度：Growlybass 文件名按键位（记谱音高）命名，`e2` 实际发声是 E1（MIDI 28），却被登记为 40，所以乐谱写 G2 时实际奏出 G1。band 1.1.0 改为按实际发声登记根音，音域为 28–60，每 5–6 个半音一个根音，最大移调从 ±7 半音降到 ±3 半音。短奏贝斯从 5 次轮换中挑选音高最清晰的两次，因为部分短奏录音被品丝噪声主导或音高偏移。吉他与贝斯的 `tuningCents` 现为实测值；钢琴保留 Salamander Retuned SFZ 的调律。

`scripts/prepare-common-instruments.mjs` 生成时会用 `src/pitch.ts` 逐个测量音高：八度不符直接中止，没有显式调律的根音取各层与各轮换的平均实测偏差。`tests/instrument-pitch.test.ts` 对所有内置采样区做同样检查（允许 25 音分误差）。starter 1.1.0 只把资产 ID 和文件名改为实际根音，例如 `starter-recorder-60` 改为 `starter-recorder-72`，音频内容不变。

乐谱会内嵌乐器定义和采样的完整副本，所以修好的包不会自动作用到已有乐谱。`import-pack` 会在定义里写入 `pack: { id, version, digest }`；`validate` 与 `diagnose` 在包已更新时给出 `STALE_PACK_INSTRUMENT` 警告，并附上修复命令：

```bash
node dist/cli.js import-pack song.json --pack band --instrument band-bass --replace --out song.json
```

`--replace` 移除旧定义及只有它引用的采样后重新导入，轨道无需改动。导入后调整的增益、包络不会触发警告；没有 `pack` 字段的旧导入按采样映射（资产、根音、调律、音区、力度、轮换）和采样哈希比对。

## 力度分层与轮换

`sample.zones` 与 `drumKit.slots` 均新增可选字段：

```json
{
  "lowVelocity": 1,
  "highVelocity": 79,
  "roundRobin": 1
}
```

速度边界为 MIDI 力度 1–127，含两端。音符/击打的 `velocity` 仍为 0–1，编译器用 `round(velocity * 127)` 匹配，并计入 clip 的力度缩放和 humanize。力度为 0 的事件不播放，也不推进轮换。
旧映射缺省为完整 1–127、`roundRobin: 1`，旧样本选择保持兼容。公开 JSON Schema 以输入模式导出，带默认值的字段可省略，与运行时一致。

同一音区、根音和力度范围可声明多个不同的 roundRobin 值（1–16）。鼓件以 sound 与力度范围分组。重复编号、部分重叠的歧义映射会报错。
选择由 score seed 和每条轨道的局部计数决定，编译结果带 `sampleZoneIndex` 或 `sampleDrumSlotIndex`。循环重复同一轮选择，solo 不受其他轨道影响，片段导出不从零重新轮换。不会调用运行时随机数。
连奏会保持当前采样；若下一音需要切换音区或力度层，则需重新触发，编译器会明确报错。

所选库的力度层被精简并扩展覆盖完整力度范围；没有复刻原 SFZ 的完整力度曲线、释放触发、反馈、GUI 或控制器。鼓组只提供五件真实采样，crash/rim/clap 保留现有合成回退，不包含原库的多麦克风混合与踩镲互斥控制。

## 试听与出处

主页面的三首场景配乐使用这些音源，附可下载的可移植乐谱。可以参考其音区、力度与混音设置，在自己的乐谱中导入所需乐器后渲染。独立音色展示界面已移除。

- band：Karoryfer 的 Growlybass，以及 Black And Green Guitars；吉他录音 Brian Wood，CC0。
- piano：Alexander Holm 的 Salamander Grand Piano V3，调音映射 Markus Fiedler，CC BY 3.0。
- drums：Karoryfer Lecolds 的 Gogodze Phu Vol II，CC BY 4.0。

每个正式包都附有许可/上游说明、`ATTRIBUTION.md`、`SOURCES.json`。后者记录原文件和处理后文件的 SHA-256、映射与处理方式。内嵌到 JSON 的样本也携带作者、许可链接、来源和改动摘要；分发钢琴、鼓组及其衍生内容时保留适用署名、许可和改动说明，不能把这些录音当作 MIT 素材重新授权。

## 原始素材的处理

`material/` 和 `material-library/` 是用户本地归档，已加入 `.gitignore`，不属于项目交付。没有删除或修改其中的原文件。
整理完成后可以自行移走或删除它们；常规使用不受影响。只有可选的素材重建脚本需要原始归档：

```bash
node scripts/prepare-common-instruments.mjs --source /path/to/material
```

准备脚本需要 ffmpeg；正常渲染没有新增依赖，也不会自动执行准备脚本。
