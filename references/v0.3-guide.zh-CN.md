# 第三版：独立音色、演奏表情与主题发展

工具包版本 **0.3.0**。新工程推荐 `schemaVersion: "1.1"`；旧的 `"1.0"` 乐谱继续接受。CLI 与第二版编辑操作保持兼容。新增字段为可选扩展，不会要求重写旧工程。

## 1. 独立音色定义

11 个原预设已经迁移到 `scripts/runtime/src/instrument-data/*.json`，由 `catalog.ts` 显式注册。修改已注册 JSON 后执行 build 即可更新。新增自定义音色无需修改渲染器，推荐导入到工程的 instrumentDefinitions 中。

```json
{
  "instrument": {
    "id": "my-fm-lead",
    "engine": "fm",
    "role": "melody",
    "range": [60, 96],
    "attack": 0.01,
    "release": 0.08,
    "description": "Original expressive FM lead",
    "synthesis": {
      "harmonicity": 2,
      "modulationIndex": 3,
      "sustain": 0.6,
      "volumeDb": -7
    },
    "velocityResponse": {
      "filterOctaves": 1.5,
      "fmIndexScale": 1
    },
    "provenance": "Original procedural preset"
  },
  "assets": []
}
```

保存为本地 instrument-package.json 后：

```bash
node dist/cli.js import-instrument examples/pixel-trail.json --definition instrument-package.json --out output/with-instrument.json
```

导入不会自动替换轨道乐器。使用已有 patch 的 set-track 修改 instrument，或直接修改 JSON 后 validate。自定义 ID 不可覆盖内置 ID，不可重复；音色查找按工程定义和固定内置目录完成，不使用进程全局可变注册表。

### 支持的声音参数

| 参数 | 用途 |
| --- | --- |
| engine | pulse、triangle、fm、sample、drums |
| attack / release | 秒数；计入实际发声与声部资源 |
| synthesis.pulseWidth | 脉冲波宽度 -0.95..0.95，0 表示对称波形 |
| synthesis.harmonicity | FM 频率比例 |
| synthesis.modulationIndex | FM 基础调制指数；省略时使用轨道 brightness 的映射 |
| synthesis.decaySeconds | 固定衰减秒数；省略时使用轨道 pluckiness 的映射 |
| synthesis.sustain | 持续电平比例 |
| synthesis.volumeDb | 合成器输出电平；采样使用区域 gainDb |
| velocityResponse.filterOctaves | 以 velocity=.5 对应 4 kHz 的声部滤波器，力度驱动截止频率 |
| velocityResponse.fmIndexScale | 力度驱动 FM 调制指数，0 表示关闭 |

FM 使用 Tone.FMSynth 两运算器，并非 YM2612 四运算器仿真；drums 引擎仍使用原有三种程序鼓，尚未提供任意鼓组采样映射。音色参数不会自动保证音质，需要标准试听与曲中试听。

## 2. 多音区 WAV 与可移植工程

可运行例子：`examples/instruments/original-flute-package.json`，含两个原始程序生成 WAV，以及根音校准、音区和循环边界。

```json
{
  "instrument": {
    "id": "my-flute",
    "engine": "sample",
    "role": "melody",
    "range": [60, 84],
    "attack": 0.02,
    "release": 0.1,
    "description": "My original sample instrument",
    "sample": {
      "kind": "zones",
      "zones": [
        {
          "lowMidi": 60,
          "highMidi": 84,
          "rootMidi": 72,
          "assetId": "flute-c5",
          "tuningCents": 0,
          "gainDb": 0,
          "loopStartFrame": 1000,
          "loopEndFrame": 4000
        }
      ]
    }
  },
  "assets": [
    { "id": "flute-c5", "file": "flute-c5.wav", "provenance": "Original recording" }
  ]
}
```

上述为字段示意；循环点必须替换为实际样本中可用的位置。file 按 package JSON 所在目录解析。当前导入支持单/双声道 PCM16 WAV，采样率 8–96 kHz；单资产最多 768000 帧，工程总计最多 4000000 个声道帧。

导入后，音色定义与 Base64 WAV 写入工程的 instrumentDefinitions / sampleAssets。浏览器渲染不再依赖原文件路径或网络 URL。保持源 WAV 采样率，以 rootMidi 和 tuningCents 校正播放速率。tuningCents 为“原素材比声明根音偏高的音分数”，播放时会反向补偿。

音区是闭区间，不允许重叠。循环帧采用源 WAV 的 `[start,end)`，两个边界必须成对提供，且位于样本以内；不设置则单次播放。source 从音头开始，到达循环区域后才循环持续段。根音错误、循环纹理不自然和立体声相位问题仍需试听判断。

```bash
node dist/cli.js import-instrument examples/pixel-trail.json --definition examples/instruments/original-flute-package.json --out output/portable.json
node dist/cli.js audition --score examples/v3-starfall-sample.json --instrument sample-original-flute --out output/my-flute-audition
```

自定义音色试听使用相同标准参考谱和 RMS/峰值限制。若推荐音域包含未覆盖的音区，渲染会明确报错，方便修正音色定义。

## 3. 连奏、滑音、弯音

```json
[
  { "id": "held", "kind": "note", "at": 0, "pitch": "E5", "duration": 1, "gate": 1 },
  {
    "id": "slide",
    "kind": "note",
    "at": 1,
    "pitch": "G5",
    "duration": 1,
    "gate": 1,
    "articulation": "legato",
    "expression": { "portamentoBeats": 0.25 }
  }
]
```

- 省略 articulation 或填写 retrigger，按普通重触发处理。
- legato 要求同轨 maxVoices=1，且前一个有声音高事件仍处于按键持续阶段。release 尾音不算“仍按住”。
- 连奏链共用音源和振幅包络，换音时不重新触发音头。后续力度通过额外增益比控制；力度音色响应按各音符重新设置。
- portamentoBeats 仅用于 legato；以音分线性插值，即频率按指数变化，且不得长于当前音的门长。
- 第一条发声音符不能凭空 legato；不支持从前一循环的末音直接连奏至本轮第一音。循环入口使用重触发。
- 采样连奏保持同一个播放源，不能跨 sample zone；跨区请重触发。单次衰减采样不会因为 legato 自动变成持续音。

弯音曲线：

```json
"expression": {
  "pitchBendCents": [
    { "offsetBeats": 0, "value": -100 },
    { "offsetBeats": 0.125, "value": 0 },
    { "offsetBeats": 1, "value": 25 }
  ]
}
```

offsetBeats 从该音符起点计算，必须递增、位于名义音长内，并符合 PPQ 网格。曲线在音分域线性插值；第一点不在零时，从零弯音开始插值；最后一点之后保持。新音符会恢复自己的弯音/颤音状态，不继承上一音的尾值。

原有 vibrato 继续可用，rateHz 按真实秒计算。滑音、弯音与颤音相加，按约 100 Hz 控制点调度并以线性斜坡连接。没有实现音频采样率级别的调制或任意曲线形状。

## 4. 轨道自动化

```json
"automation": [
  { "parameter": "gainDb", "points": [{ "at": 0, "value": -12 }, { "at": 8, "value": -6 }] },
  { "parameter": "brightness", "points": [{ "at": 0, "value": 0.3 }, { "at": 8, "value": 0.6 }] }
]
```

支持 gainDb、pan、brightness、send，每种参数最多一条 lane。at 为工程全局拍点；点位严格递增，不能超出工程长度。未给零点时，从轨道基础值开始。每个循环入口重新建立起始状态；要避免边界突变，建议让末尾值自然回到起点。

gainDb 映射到线性增益，brightness 映射到轨道低通频率，之后按 Web Audio 参数值做线性斜坡。brightness 自动化不改变固定的 FM modulationIndex；力度到音色的响应由独立声部滤波和调制指数承担。

## 5. 编曲骨架

```bash
node dist/cli.js arrange examples/arrangement-config.json --out output/skeleton.json
```

支持 exploration / battle / town / stealth，AABA / ABAB / ABAC，指定速度、拍号和每段小节数。输出 **空乐谱骨架** 和 `.plan.json`，包含段落意图、声部任务、共享主题引用，以及一个通过静音 arp 表达的减法对比。

A 段各次引用共享 A pattern；修改一次会影响所有引用。需要 A2 独立句尾时再 vary。energy 是任务提示，不会自动生成节奏、和声、旋律或混音动态。

## 6. 受约束的主题变奏

```bash
node dist/cli.js vary examples/v3-base-fm.json --config examples/v3-variation-config.json --out output/variant.json
```

该命令从未变奏的 base 工程生成独立句尾。接着可运行 `answer output/variant.json --config examples/v3-answer-config.json --out output/answered.json`。最初生成流程在 scripts/create-v3-examples.mjs 中展示。

两种模式：

- ending：保留 fromBeat 之前的全部事件，用 AI 提供的 replacementEvents 替换后半句。replacementEvents.at 仍为 pattern 内绝对位置，不能改到保留区。若前半句长音跨越边界，会拒绝操作，要求先明确拆分。
- simplify：从指定 clip 的 pattern 副本中删除明确给出的 removeEventIds，并保护 fromBeat 之前的事件。

工具先复制 pattern 并只重定向指定 clip，原主题和其他引用保持不变。若该 clip.repeats > 1，修改会影响该 clip 的全部重复。新谱与 `.changes.json` 报告一并输出，不自动选择音高或判断和声正确。

## 7. 把回答放进休止

```bash
node dist/cli.js answer SCORE.json --config ANSWER_CONFIG.json --out output/answered.json
```

config 字段为 leadTrackId、leadClipId、answerTrackId、newPattern、candidates（完整 note 事件数组，位置相对所选 lead pattern）。工具筛选能完整放进主旋律空白的候选，计入双方 release，检查其他 lead clips 和跨循环尾音。接受和拒绝的候选 ID 都写进报告；没有合适候选时明确失败。

回答声部必须已经存在且不同于 lead；它的其他编曲冲突由最终编译检查。最终仍需试听和声与非主旋律声部的遮蔽问题。

## 8. 完整示例与 API

- `examples/v3-starfall-fm.json`：原创 16 小节，独立 FM 音色、A2 句尾变奏、回答、连奏/滑音、弯音与自动化。
- `examples/v3-starfall-sample.json`：同主题采样改编，带两个原始 WAV 的嵌入数据、根音校准和循环点。
- `examples/v3-empty-scaffold.json`：空骨架；plan 明确列出尚需 AI 创作的任务。
- `npm run examples:v3`：构建并重新生成所有第三版示例及原始程序样本。

```ts
import { createArrangement, importInstrument, varyMotif, placeAnswers, renderScore } from './dist/index.js';
const { score, plan } = createArrangement({ form: 'AABA', barsPerSection: 4 });
// AI fills notes/harmony before rendering; the plan is not a finished composition.
const embedded = await importInstrument(score, instrumentPackage, '/absolute/assets/directory');
const changed = varyMotif(composedScore, variationOptions);
const answered = placeAnswers(changed.score, answerOptions);
const audio = await renderScore(answered.score);
```

第三版未加入简写记谱、MIDI、MCP server、tempo map 或完整芯片仿真。音频检查验证执行与信号，不能代替主观听感评审。

节奏缩放会同时缩放 gate 所依据的名义音长、颤音延迟、滑音时长和弯音点偏移。慢起音诊断只检查重新触发音头的音符，不把连奏换音当成一次新起音。
